## Тема
Разработка ПО разграничения полномочий пользователей (система разграничения доступа).

## Реализовано

### Общая часть (п. 1–13)
- Два режима: ADMIN / обычный пользователь
- Фиксированный логин администратора `ADMIN`
- Смена пароля (с проверкой старого)
- Просмотр списка пользователей (JTable)
- Добавление пользователя с пустым паролем
- Блокировка/разблокировка учётных записей
- Маскировка пароля символом `*`
- Повтор ввода имени / 3 попытки пароля → завершение
- Шифрованное хранилище `users.dat` (AES-128/CBC)
- Меню, панель инструментов, строка состояния
- «Справка → О программе»

### Индивидуальное задание П/Г-1
**Часть 1 — политика паролей (индивидуально для каждого пользователя):**
- минимальная длина из учётной записи
- строчные + прописные буквы
- цифры + знаки препинания
- отсутствие повторяющихся символов
- отчёт о выполнении **каждого** требования

**Часть 2 — аутентификация по сертификату на USB:**
- выпуск сертификата открытого ключа (формула CA≪A≫)
- ЭЦП УЦ алгоритмом `SHA256withRSA`
- хранение `auth.cert` на USB-носителе
- настройка имени диска в `config.properties`
- проверка подписи и срока действия при входе

### Блоки СРД
1. Идентификация и аутентификация субъектов
2. Диспетчер доступа (разграничение ADMIN/USER)
3. Криптографическое закрытие при хранении (AES + SHA-256 хеш паролей)
4. Регистрация событий (`audit.log`)
5. Очистка оперативной памяти (`SecureMemory.wipe`)

## Демонстрация USB-входа без флешки
1. Войти как ADMIN
2. Добавить пользователя `ivan`
3. «Настройка USB-диска» → указать, например, `C:\temp\`
4. Выделить `ivan` → «Выпуск USB-ключа»
5. Выйти, нажать «Вход по USB-сертификату»
